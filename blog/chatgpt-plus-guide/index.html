ChatGPT Plus 怎么用？开通后的新手教程

AIchongzhi.org 编辑部 · 首发：2025-09-20 · 更新：2026-09-15

ChatGPT Plus 不需要另装一个“Plus 软件”。登录开通会员的同一个 ChatGPT 账号，就能在网页或官方 App 中使用对应权益。刚开通不知道从哪里开始，按下面三步操作即可。

第一次购买 ChatGPT Plus，容易把会员、模型和 API 余额混为一谈。Plus 是账号订阅，不是每次提问都要另外充值的点数；免费版也能完成一些日常任务，升级主要是为了更高的使用额度和更多工具访问。下面先讲开通后的实际用法，再说明购买与到账问题。如果你只是偶尔问答，可以先试免费版；已经经常遇到额度不足，再考虑付费。

ChatGPT Plus 开通后，先做这三步

  1. 确认会员到账：打开 ChatGPT 的个人菜单 → 设置 → 账号，核对方案名称。使用购买时的账号和登录方式，尤其留意 Apple 隐藏邮箱。
  2. 从一个真实任务开始：新建对话，写清“要做什么、已有材料、希望输出什么”。复杂分析可选择账号当前提供的推理选项。
  3. 检查结果：让回答附上来源、计算过程或文件页码，重要数字回到原始资料复核。付费会员也可能回答错误。

入口名称可能随客户端版本变化；模型和额度以账号界面为准，不必照着旧教程找固定模型名。

读文档：上传文件，再明确提问

通过对话中的附件入口上传文档，先做提取和核对，再要求总结。下面的示例提示词可以按你的材料调整：

请读这份产品说明，列出功能、适用条件和限制。每项注明页码；文档没写的内容标注“未说明”，不要推测。

分析表格：先校验，再汇总

上传已脱敏的表格，明确字段与统计口径，避免只说“帮我分析”。

按月份汇总这张表的销售额。先检查空值、重复行和金额格式，再输出汇总表，并列出被排除的记录及原因。

Plus 还提供扩展的语音、图像生成和研究工具访问。具体功能可用性见 OpenAI 的 Plus 说明；文件里不要上传密码、验证码或未经授权的客户资料。

免费版和 Plus 有什么区别？值得买吗？

区别不在于“免费版完全不能用”，而在于可用模型、工具范围和使用额度。偶尔写邮件、问问题，先用免费版；经常处理材料、做研究或用 Codex，且额度已经影响工作，再考虑 Plus。它仍有用量限制，并不是所有功能无限使用。

如果你正在纠结更贵的会员，看 Plus 和 Pro 的价格、额度与选择对比，不用直接跳到 200 美金档。

ChatGPT Plus 多少钱？怎么开通？

官方 Plus 标价为 20 美元/月；本站 Plus 商品价为 ¥178/月（2026-09-15 核对）。两者是不同渠道的报价；税费、币种和最终应付金额以各自结账页为准。

自行订阅可登录 ChatGPT，在个人菜单选择升级方案 → Plus。需要本站服务，可先查看 Plus 当前价格和办理条件，再购买卡密并按商品页流程操作。

本站当前 Plus 卡密需在购买后 24 小时内使用，不能多月叠加；Outlook / Hotmail 邮箱不在商品质保范围内。先确认账号条件和售后，再付款。

已经付款，为什么还是显示 Free？

  1. 先核对是否登录了购买时的同一个账号，以及相同的 Google、Apple、Microsoft 或邮箱登录方式。
  2. 如果是你自己在官方 iOS / Android App 内订阅，可尝试设置中的“恢复购买”；这不是给未购买的账号免费开通。
  3. 仍未到账，保留订单并联系原购买渠道，不要连续重复付款。向本站咨询时先提供订单号和打码报错，不要发送密码或验证码。

两个容易弄混的问题

Plus 包含 API 余额吗？

不包含。ChatGPT 订阅和 API 使用分开计费，买了 Plus 不代表 API 调用免费。

用 Codex 还要另买会员吗？

Plus 包含对应 Codex 访问，使用 ChatGPT 账号登录；API Key 登录则走另一套计费。遇到登录卡住，先看 Codex 验证排查，不要为解除验证重复购买。参见 Codex 方案说明。
