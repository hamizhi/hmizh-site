Codex · 登录排查

Codex 登录要手机号验证怎么办？收不到验证码的排查步骤

AIchongzhi.org 编辑部 · 首发：2026-07-22 · 更新：2026-09-15

先看清要求的是哪一种验证码，不要先重复购买 Plus。手机号、邮箱验证码和设备授权码不是一回事；升级会员也不是官方承诺的免验证办法。

使用 Codex 时，终端、浏览器和账号页面可能先后出现不同提示。“登录成功但回不到客户端”和“必须填写手机号”需要分别处理。即使 ChatGPT 网页能正常使用，也不能据此认定 Codex 当前授权已经完成；已有 Plus 也不意味着任何验证都会消失。下面按实际看到的页面分流，不把账号验证问题包装成充值后一定能解决的问题，也不建议为了反复尝试而重新付费。

按当前提示排查我遇到哪种验证短信收不到账号或授权不对买 Plus 能解决吗

先分清：你看到的是哪种验证？

  • 要求填写手机号，或地址含 add-phone：说明当前流程停在手机号验证。不能只凭这一步认定你选错了 API 登录，也不要把它当作会员未到账。
  • 正在创建第一个 API Key：OpenAI 手机验证说明列出了首次创建 API Key 的手机号要求；Plus 不会自动取消它。
  • 要求邮箱验证码或 MFA：使用页面指定的邮箱或验证器，不要把短信码填进另一种验证框。
  • 终端显示 Device Code：这是设备授权码，按终端显示的官方网址完成授权，不是等待手机收到短信。

OpenAI 的一般账号说明不能替代你当前的验证页面。遇到额外验证，应完成页面要求或联系官方支持，不应假定“换登录方式就一定免验证”。

手机号验证码收不到，按这个顺序检查

  1. 核对地址与区号：确认是 OpenAI 官方页面、国家区号和你能长期控制的手机号；不要在仿冒网页输入验证码。
  2. 看清接收渠道：页面若写 WhatsApp，就检查 WhatsApp；短信验证则检查短信和运营商拦截。手机验证不能改成发到邮箱。
  3. 暂停连续重发：按页面倒计时等待，收到多条时使用最新验证码。请求过密或登录被临时限制时，先停止重复尝试。
  4. 仍然失败：记录时间、客户端版本和完整错误文字，向 OpenAI 支持反馈。截图遮住手机号、邮箱和授权码；不要提交密码或登录凭据。

接收渠道依据 官方手机验证说明。不建议使用临时接码号码，避免后续无法找回账号。

登录了错误账号，或授权后没有返回 Codex？

先用原注册方式登录同一个 ChatGPT 账号。CLI 用户可以运行只读检查：

codex login status

只有确认账号或认证方式错误，且需要重新授权时，再执行以下命令。退出会清除当前登录状态，不是解除手机号验证的命令。

codex logout
codex login

浏览器中选择自己的 ChatGPT 账号完成登录。远程终端打不开浏览器或本地回调受阻时，如果账号或组织允许设备授权，可用 codex login --device-auth；这同样不会绕过账号验证。

桌面端或 IDE 扩展先检查当前账号和登录方式；界面名称随版本变化。操作依据 Codex 官方认证文档。普通登录报错另见 OpenAI 登录故障说明。

升级 Plus 能解决 Codex 手机验证吗？

不能保证，也不应只为免验证而购买。会员权益、登录认证和账号安全检查是不同问题。先把登录恢复正常，再决定是否需要更高用量，避免把充值当作解除验证的操作。

如果登录已经正常，真正的问题是 Codex 用量不够，再看 Plus 与 Pro 额度对比。使用 ChatGPT 账号登录走对应订阅权益；使用 API Key 则另按 API 计费，见 官方方案说明。

已经是 Plus，还需要再充一次吗？

不要因验证提示重复充值。先确认登录的是付费账号，再处理验证；如果是本站订单未到账，可以联系本站核对。本站可以协助核对充值订单，但不能代替 OpenAI 解除账号安全验证。
